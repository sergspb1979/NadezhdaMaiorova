# WebSiteNadya — сайт Нади

## Структура файлов

```
index.html        — главная страница
recommend.html    — страница рекомендаций
style.css         — стили
script.js         — скрипты
img/              — картинки (фото, иконки, видео)
Inbox/            — черновики
```

## Деплой на сервер

Из папки проекта запустить:
```
node deploy.js
```

Заливает файлы по SFTP на сервер (библиотека `ssh2`).

- **Сервер:** 194.156.65.125
- **SSH:** root, пароль `YnteGRK=pz$_Ws`
- **Путь на сервере:** `/var/www/nadya/` (настроить в `SERVER.remotePath` в deploy.js)
- **Nginx:** нужно настроить конфиг для этого сайта (домен или порт)

Если нужно добавить новый файл в деплой — добавить запись в массив `files` в `deploy.js`.

## Важно

- Деплой НЕ зависит от git (деплой через `node deploy.js`)
- Для доступа по SSH из Claude Code используется библиотека `ssh2` (Node.js), т.к. встроенный `ssh` не работает на Windows с кириллическими путями
- Если нужно выполнить команды на сервере — писать Node.js скрипт аналогично `check-server.js` из проекта mnemonic-trainer
